# Upwork portfolio entry

## Title
AI Front Desk for a Dental Clinic: Bookings, FAQ, Reminders (n8n + AI, Arabic/English)

## Description (120 words)
Clinic front desks lose hours daily to repetitive messages, and missed appointments cost real money. I built an AI front desk that handles patient messages 24/7 in Arabic and English.

It reads every message from the website form or a chatbot and books appointments into Google Sheets. It sends confirmations in the patient's language and answers price and opening-hour questions strictly from the clinic's FAQ. Complaints and emergencies reach staff on Telegram within seconds. Confirmed patients get an automatic reminder the day before, which cuts no-shows. The team also receives a daily summary every evening.

It is built for production: a secured webhook, validated AI output with retries, instant error alerts, and no secrets in code. Setup takes 15 minutes.
